🔍 Test de connexion au Backend Laravel

Instructions

  1. Assurez-vous que le backend Laravel est démarré : php artisan serve
  2. Le backend doit être accessible sur http://localhost:8000
  3. Cliquez sur le bouton "Tester la connexion" ci-dessus

Si le test échoue :

  • Vérifiez que PHP 8.2+ est installé : php -v
  • Installez les dépendances : cd backend && composer install
  • Créez le fichier .env : copy .env.example .env
  • Générez la clé : php artisan key:generate
  • Démarrez le serveur : php artisan serve
